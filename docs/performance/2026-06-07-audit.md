# Performance audit — 2026-06-07

**Site:** oidib.io (Next.js 15.5.15, Vercel)  
**Scope:** Homepage (`/`), Silk Analyzer (`/analyze`), WorkshopChat path  
**Method:** `npm run build` route analysis, static code review (LCP/CLS/INP risk tree)

## Findings

### LCP — Largest Contentful Paint

| Issue | Impact | Recommendation | Expected improvement |
|-------|--------|----------------|----------------------|
| Hero is text (h1), not an image — good | LCP element is likely the h1 or badge | Keep hero image-free; ensure font loads fast | Baseline OK |
| **Google Fonts `<link>` in layout** blocked render and fetched 7 weights (300–900) from CDN | **High** — delays FCP/LCP, FOUT risk | **Done:** migrate to `next/font/google` (`Outfit`) | Faster FCP; zero-CLS font swap |
| Entire homepage is `"use client"` | Medium — all route JS hydrates before interactivity | Future: split static sections into Server Components | Lower TTFB-to-interactive on `/` |
| `WebWeaveBackground` + `SilkTrail` run continuous `requestAnimationFrame` on load | Medium — competes with main thread during LCP window | **Done:** `dynamic(..., { ssr: false })` on homepage; skip rAF when `prefers-reduced-motion: reduce` | Less main-thread work at load |
| `ScrollReveal` applies `blur` + `translate-y` on hero children | Low — opacity/transform are composited; blur filter is heavier | Consider removing blur on hero `ScrollReveal` only (future) | Marginal LCP |

### CLS — Cumulative Layout Shift

| Issue | Impact | Recommendation | Expected improvement |
|-------|--------|----------------|----------------------|
| Manual Google Fonts without metrics | **High** — swap can shift headings | **Done:** `next/font` with `display: swap` + automatic fallback metrics | CLS → near 0 for typography |
| `WeaveMotionStage` fixed `aspect-[16/10]` + min/max height | Low — reserved space | **Done:** skeleton placeholder during dynamic load | No shift when stage chunk arrives |
| Dynamic sections without placeholders | Low | **Done:** min-height shells for Landscape, DatabaseGrid, Analyzer on `/` | Stable scroll layout |
| Workshop chat FAB appears after results | Low — fixed position, bottom-right | Acceptable; no in-flow shift | — |

### INP — Interaction to Next Paint

| Issue | Impact | Recommendation | Expected improvement |
|-------|--------|----------------|----------------------|
| Dual canvas loops + mousemove listeners | **Medium** — long tasks on scroll/input | **Done:** defer effect bundles; respect reduced motion | Better INP on low-end devices |
| `WeaveMotion` CSS: 15+ simultaneous 22s keyframe animations | Medium — GPU/compositor load when section visible | **Done:** dynamic import + existing `motion-reduce` static cards | Animations off main critical path until scroll |
| `WorkshopChat` re-renders `MessageContent` on every keystroke | Low | **Done:** `memo(MessageContent)` | Fewer subtree reconciliations while typing |
| `AnalyzerResults` (~650 lines) in initial `/analyze` graph | Medium | **Done:** dynamic import with loading state | Smaller initial parse/hydrate |

### Bundle / client boundaries

- **~50 files** with `"use client"` — homepage pulls analyzer flow, grid, modal, and effects into one client tree.
- **No `next/dynamic` usage** before this audit (only mentioned in gloss copy).
- **No hero images** — no `next/image` LCP work needed on `/`.
- **PlatformShell** (`/analyze`) still eagerly loads canvas effects — acceptable for analyzer UX; same reduced-motion guard applies.

## Quick wins implemented

1. **`src/lib/fonts.ts`** — `Outfit` via `next/font/google`; removed render-blocking `<link>` tags from `layout.tsx`.
2. **`src/app/page.tsx`** — dynamic imports: `WebWeaveBackground`, `SilkTrail`, `LandscapeSection`, `DatabaseGrid`, `AnalyzerSection`, `Modal` (with layout placeholders where useful).
3. **`src/components/AnalyzerSection.tsx`** — dynamic imports: `AnalyzerResults`, `CompareResults`, `WorkshopChat`.
4. **`src/components/LandscapeSection.tsx`** — dynamic imports: `WeaveMotionDescriptors`, `WeaveMotionStage` (`ssr: false` + aspect-ratio skeleton).
5. **`src/components/effects/WebWeaveBackground.tsx`**, **`SilkTrail.tsx`** — skip animation when `prefers-reduced-motion: reduce`.
6. **`src/components/WorkshopChat.tsx`** — `memo(MessageContent)`.

No visual redesign. Patterns match existing `dynamic` + loading-shell approach.
